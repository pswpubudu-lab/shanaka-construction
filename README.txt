SHANAKA CONSTRUCTION WEBSITE
=============================

FILES
- index.html: Website content
- style.css: Responsive design and styling
- script.js: Mobile menu and WhatsApp buttons

BEFORE PUBLISHING
1. Open script.js in a text editor.
2. Find: const WHATSAPP_NUMBER = "REPLACE_WITH_YOUR_NUMBER";
3. Replace the placeholder with your WhatsApp number in international digits only.
   Sri Lanka format example: 94771234567 (example only; use your own number).
4. In index.html, replace the sample project images/text with photos and details from your real projects.
5. Check that all services listed are services you actually offer.

FREE PUBLISHING WITH GITHUB PAGES
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new public repository, e.g. shanaka-construction.
3. Upload index.html, style.css, script.js and any other assets to the repository root.
4. Open repository Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait a few minutes; GitHub will show your published URL, usually:
   https://YOUR-USERNAME.github.io/shanaka-construction/

NOTES
- GitHub Pages offers free static hosting. A custom .com domain is optional and usually costs money.
- This is a static website; it does not include a booking database or admin dashboard.
- Project images load from Unsplash and require internet access. Replace them with your own photos for a more authentic business website.
- The WhatsApp button uses the number you enter in script.js. Test it on your phone before sharing the website.
